# Especificações Oficiais de UX

Esta pasta contém as especificações normativas de experiência do usuário da Central Operacional.

Esses documentos complementam:

- Constituição
- Source of Truth
- Arquitetura
- Planos de Implementação

Seu objetivo é definir o comportamento visual, organização, nomenclatura e critérios de aceitação das interfaces.

Toda implementação de interface DEVE referenciar a especificação de UX correspondente.

Ausência de especificação oficial implica inexistência de decisão de UX para fins de implementação.
